# Reproduction scope

The publication release retains the original scientific source and configuration hashes. The main benchmark settings were frozen before its own check outcomes, after earlier pilot and uncertainty-envelope investigations. Historical manifests are included only to preserve the original audit's immutability checks; the earlier studies are not the paper's results.

`install_reference.py` verifies the archive and every extracted file, refuses path traversal and refuses to overwrite changed local files. `verify_release.py` checks the distributed subset, frozen scientific source and all prepared operator files. The original main manifest records 574 output hashes, including large arrays omitted from Git. This deliberate subset is explicitly distinguished from a full raw-output archive.

`reproduce_benchmark.py` runs the primary experiment in a fresh directory with unchanged source and protocol. It then runs `verify_reproduced_benchmark.py`, a publication entry point to the unchanged independent auditor. All primary numerical, dense-likelihood, source/output and prepared-operator checks run unchanged. References are reconstructed using NumPy/SciPy rather than importing the scientific information implementation. Raw anatomy and unrelated prior-study outputs are not needed for this primary reproduction: available upstream files are checked strictly, while absent upstream files are explicitly listed as checks not repeated. The original full-workspace auditor remains available as `verify_ceiling_benchmark_outputs.py`. Finally it compares all primary summary fields with the published execution. Small floating-point differences across supported libraries or hardware may occur; the comparison uses relative tolerance 1e-9 and absolute tolerance 1e-10.

The source includes the original additional calibration, conductor sensitivity and transfer diagnostic scripts. Their frozen numerical outputs are in the reference archive. Rebuilding conductor surfaces from scratch requires the original public anatomy files and checksummed archives described in `ANATOMICAL_PROVENANCE.md`; the script `prepare_ceiling_assets.py` intentionally expects those staged inputs rather than silently downloading different versions. The primary reproduction uses the supplied operators and needs no raw EEG or MRI download.

The finer-model transfer diagnostic can be repeated using the restored gain arrays and frozen encoders with `scripts/diagnose_ceiling_transfer_resolution.py` in a new result directory. Original scripts reject completed output directories; do not delete or overwrite the reference results to force a rerun. The fully audited calibration replay arrays are not distributed, but the original replay checks and summaries are retained.

Implementation checks are conditional on the declared models. They do not establish continuous-population uncertainty coverage, biological realism, or cortical source-resolution convergence.
